# Raw data

Files in this folder are the data **exactly as you got them**. Never edit them by hand: every
change (fixing values, dropping rows, renaming columns) happens in code, so anyone can see and
repeat it. If a file is too big for GitHub (over ~50 MB), commit a script that downloads it instead.

For every file, write down:
